# Cellular Metabolism Practice Questions

A comprehensive, interactive quiz with 935 carefully curated practice questions covering cellular metabolism. Perfect for students studying biochemistry, cell biology, or preparing for medical exams.

## Features

- **935 Practice Questions** - Comprehensive coverage of cellular metabolism topics
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Progress Tracking** - Save your progress automatically and resume where you left off
- **Smart Filtering** - Filter by topic or module to focus on specific areas
- **Answer Revealing** - Review answers with detailed explanations
- **Question Flagging** - Mark important or challenging questions for review
- **Score Tracking** - Monitor your performance across different topics
- **Shuffling** - Randomize question order for varied practice sessions
- **Mobile Optimized** - Touch-friendly interface with large tap targets
- **Offline Ready** - Works completely offline after initial load

## How to Use

1. **Open the Quiz** - Open `index.html` in any web browser
2. **Start Practicing** - Click on multiple choice options to select your answer
3. **Check Your Answer** - Click "Show Answer" to reveal if you got it correct
4. **Flag Questions** - Click the flag icon to mark questions for later review
5. **Track Progress** - Use the score display to monitor your performance
6. **Filter Topics** - Select specific topics to focus your studying
7. **Save Progress** - Your answers are automatically saved to your device

## Deployment

### Option 1: GitHub Pages (Recommended)

1. Fork or clone this repository
2. Go to Settings → Pages
3. Set source to "main branch"
4. Your quiz will be live at: `https://yourusername.github.io/repository-name/`

### Option 2: Direct Hosting

Upload `index.html` to any web server:
- GitHub Pages (see above)
- Netlify
- Vercel
- Your own web server
- Any hosting service that supports static HTML files

### Option 3: Local Use

Simply open `index.html` directly in your web browser. No server required!
